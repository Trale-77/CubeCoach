# CubeCoach

A TypeScript/WebGL Rubik's cube trainer and solver built with Vite and Three.js.

## Features

- Interactive 3D cube controls.
- Beginner-method solve walkthroughs.
- CFOP practice modes for cross, F2L, OLL, and PLL.
- Scramble loading, saved practice scrambles, and replay controls.
- Local practice stats and answer checking.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
